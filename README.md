# CS420 assignments

> Historical coursework portfolio. These submissions are preserved to demonstrate past work and are not maintained as reusable software.

## Overview

This repository contains solutions from two CS420 assignments covering Bayesian networks, neural networks, Markov decision processes, reinforcement learning, and natural-language processing.

University-issued question papers are intentionally not included. The answer PDFs, notebooks, trained model artifacts, and project data are retained as portfolio evidence.

## Repository map

| Path | Topics |
| --- | --- |
| `Assignment 1/` | Bayesian networks, artificial neural networks, and convolutional neural networks. |
| `Assignment 2/` | Markov decision processes, reinforcement learning, and natural-language processing. |

Notebooks and adjacent assets should remain in their existing assignment folders because several notebooks expect local files such as `model.json`, `model.h5`, and `tweets.csv`.

## Historical environment

The notebooks record a Python 3.10-era environment. Major dependencies include NumPy, pandas, Matplotlib, scikit-learn, TensorFlow/Keras, OpenCV, pgmpy, Gym, gensim, NLTK, TensorFlow Datasets, and tqdm.

Dependency versions were not pinned and current compatibility has not been verified. The saved outputs and trained artifacts are retained to show the original results.
